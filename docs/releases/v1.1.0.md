Watch face for the Garmin Forerunner 255, with the official Habous prayer times of Morocco.

This release changes the Worker that gives the prayer times to the watch. The code of the watch face is the same as in v1.0.0. If v1.0.0 is on your watch, a new install is not necessary: the Worker is already deployed, and the watch uses it automatically.

## What is new

### Worker (prayer times service)

- **Fewer calls to the Habous site.** The Worker now gets each Habous month file one time and keeps it for 32 days. Before, it got the file again each 24 hours.
- **No repeated calls when Habous fails.** When Habous has no file for a month (`404`), the Worker waits 1 hour before the next call. When Habous fails or blocks the Worker, it waits 10 minutes.
- **Prayer times stay available when Habous is down.** The Worker keeps a second copy of each good month file for 62 days and uses it when Habous fails. The answer `502` occurs only when no copy exists.
- **Rate limit.** Each client gets 20 requests for each 60 seconds, by IP address. More requests get `429` with the header `Retry-After: 60`.
- **Stricter request checks.** The Worker accepts only the parameters `lat`, `lon` and `date`, with a strict number format. An address longer than 200 characters gets `414`.

A valid request gets the same answer as before. The JSON contract between the watch and the Worker did not change.

### Build and deploy

- The CI now deploys the Worker to Cloudflare after a push to `main` that changes the folder `worker/`, when the Worker tests pass.
- The GitHub actions of the workflow now run on Node.js 24.

### Documentation

- The README files are updated, with an image of the watch face.
- `worker/README.md` describes the cache and the limits of the Worker.

## Install

`fr255-watchface.zip` contains the watch face (`fr255-watchface.prg`) and the install steps (`INSTALL.txt`).

1. Connect the watch to the computer with a USB data cable.
2. Copy `fr255-watchface.prg` into the folder `GARMIN/APPS` of the watch. On macOS, use OpenMTP or Android File Transfer, and close Garmin Express first.
3. Disconnect the watch.
4. On the watch, hold the UP button, select "Watch Face", then select "FR255 Test Face".

## Compatibility

- The file is for the standard Forerunner 255. The 255 Music, the 255s and the 255s Music need their own build.
- The official Habous times show for a position 25 km or less from a listed city of Morocco. In all other cases, the watch calculates the times and shows them with the mark `~`.

## Known limits

- A correction that Habous publishes in a month can stay invisible until the end of that month, because the Worker keeps the month file.
- The CI cannot run the Monkey C unit tests. It only proves that they compile.
